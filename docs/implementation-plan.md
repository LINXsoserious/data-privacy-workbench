# 中文敏感数据体检台 v0.1 实现计划

日期：2026-10-25。用户已批准上一轮提出的三个功能：上传识别、确认脱敏、导出说明。采用内联实现，不等待新的设计确认。

## 目标与范围

基于 awesome-llm-apps 的 AI Data Analysis Agent 示例，保留表格上传与 Streamlit 交互方式，移除模型与 API 密钥依赖。实现手机号、邮箱、18 位身份证候选识别；用户取消误报；掩码或移除命中片段；导出 CSV 和不含原始完整命中值的 JSON 报告。

第一版处理当前会话中的数据，不自动写入上传文件，不调用模型或网络服务。身份证只检查出生日期与校验位，不核实行政区或真实身份。规则匹配结果始终称为候选。

## 文件职责

- `app.py`：上传、合成示例、复核表、前后对照、下载。
- `privacy_workbench/detection.py`：确定性识别、校验与按位置脱敏。
- `privacy_workbench/files.py`：CSV / XLSX 读取、大小与行列限制、CSV 安全导出。
- `privacy_workbench/reporting.py`：不包含原始完整命中值的报告。
- `tests/`：识别、误报取消、混合文本、输入保真、恶意表格输入和界面流程验证。
- `sample_data/demo.csv`：可公开展示的合成数据。
- `docs/upstream/`：未改动的上游参考代码与来源记录。
- `README.md`、`NOTICE`、`LICENSE`、`CHANGELOG.md`：使用、来源与版本说明。
- `.github/workflows/tests.yml`：GitHub 上运行同一测试集。
